# Application Layer Documentation

This directory contains specifications and architectural guidance for the Application Layer.

## Key Reference Specifications

- **Architecture Handbook v2.0:** Defines the complete platform architecture, dependency rules, and frozen boundaries.
- **Application Layer Design Specification v1.0:** Defines the purpose, building blocks, and rules of the Application Layer.
- **Execution Application Module Design Specification v1.0:** Defines the Execution module use cases, ports, and orchestration boundary.
